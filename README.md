# System Tools 分析與管理網頁

這是一個用於整合硬體測試 Log 分析（如 PCIe Gen6、DDR5）與部門管理（如季遊票選）的網頁介面基礎框架。

## 網頁架構說明 (HTML & CSS)

本專案採用純 HTML 與 CSS 撰寫，使用 **Flexbox (彈性盒子)** 進行排版。為了確保複雜的工程圖表與數據表能在所有裝置上維持最佳閱讀體驗，本專案刻意捨棄手機版響應式設計（RWD），全面統一為電腦版介面。

### 1. 區塊配置 (Flexbox 排版)
* `.container`: 最外層的容器，使用 `display: flex;` 讓內部的元素左右並排。
* `.sidebar` (左側導覽列): 寬度嚴格固定為 `250px`。`flex-shrink: 0;` 確保導覽列絕對不會被壓縮變形。
* `.main-content` (右側主要內容區): 使用 `flex-grow: 1;` 自動填滿剩下的空間。`overflow-y: auto;` 讓資料量過大時只在右側產生上下捲軸。

### 2. 多頁面切換機制
* 導覽列中的 `<a>` 標籤透過 `href` 屬性連結到不同的 HTML 檔案。
* 在各別的 HTML 檔案中，會在對應的 `<a>` 標籤加上 `style="color: white;"` 反白，提示使用者當前位置。

### 3. 固定電腦版型設定 (Viewport)
* 透過 HTML `<head>` 區塊中的 `<meta name="viewport" content="width=1280">` 屬性，強制所有行動裝置（手機、平板）以 1280px 的電腦螢幕寬度來渲染網頁。
* 手機用戶開啟時，畫面會等比例縮小以呈現完整全貌，使用者可依需求自行利用雙指縮放 (Pinch-to-zoom) 瀏覽細節。
