# System Tools 分析與管理網頁

這是一個用於整合硬體測試 Log 分析（如 PCIe Gen6、DDR5）與部門管理（如季遊票選）的網頁介面基礎框架。

## 網頁架構說明 (HTML & CSS)

本專案首頁採用純 HTML 與 CSS 撰寫，使用 **Flexbox (彈性盒子)** 確保在手機、平板與電腦上的排版保持固定與一致。為了保持程式碼的整潔，所有架構與邏輯說明皆整理於此。

### 1. 區塊配置 (Flexbox 排版)
* `.container`: 最外層的容器，使用 `display: flex;` 讓內部的元素（左側選單與右側內容）左右並排。
* `.sidebar` (左側導覽列): 寬度固定為 `250px`。`flex-shrink: 0;` 是確保在小螢幕上，導覽列不會被擠壓變形的關鍵設定。
* `.main-content` (右側主要內容區): 使用 `flex-grow: 1;` 自動填滿剩下的空間。`overflow-y: auto;` 讓資料量過大時只在右側產生上下捲軸，左側選單保持固定。

### 2. 多頁面切換機制
* 導覽列中的 `<a>` 標籤透過 `href` 屬性連結到不同的 HTML 檔案（例如 `index.html`、`ddr5.html`）。
* **目前位置提示**：在各別的 HTML 檔案中，會在對應的 `<a>` 標籤加上 `style="color: white;"`，讓當前所在的頁面文字反白，以便使用者識別目前所處的功能頁面。

### 3. 響應式設計 (RWD - 手機與平板優化)
* 透過 `@media (max-width: 768px)` 針對螢幕寬度小於 768px 的裝置（如手機）進行樣式覆寫。
* 將 `.sidebar` 寬度從固定的 250px 改為 `width: 35%;`。改用比例配置能避免在手機上左側選單吃掉過多右側內容區的空間，確保標題與內文不會被迫擠壓變形。
