# System Tools 分析與管理網頁

這是一個用於整合硬體測試 Log 分析（如 PCIe Gen6、DDR5）與部門管理（如季遊票選）的網頁介面基礎框架。

## 網頁架構說明 (index.html)

本專案首頁採用純 HTML 與 CSS 撰寫，使用 **Flexbox (彈性盒子)** 確保在手機、平板與電腦上的排版保持固定與一致。

### 1. 基礎設定 (Reset)
* `body, html`: 清除瀏覽器預設的邊界空白，並將高度設為 `100%`，確保網頁佔滿整台裝置的螢幕。

### 2. 區塊配置 (Flexbox 排版)
* `.container`: 最外層的容器。設定 `display: flex;` 讓內部的元素（左側選單與右側內容）左右並排。`height: 100vh;` 確保高度剛好等於使用者裝置的視窗高度。
* `.sidebar` (左側導覽列):
  * 寬度固定為 `250px`。
  * `flex-shrink: 0;`: 這是確保在小螢幕（如手機）上，導覽列不會被擠壓變形的關鍵設定。
* `.main-content` (右側主要內容區):
  * `flex-grow: 1;`: 自動填滿左側導覽列剩下的所有可用空間。
  * `overflow-y: auto;`: 當右側內容資料量過大（例如長篇的 Log 圖表）超出螢幕高度時，只會在右側產生上下捲軸，左側選單會保持固定不動。# work_space
