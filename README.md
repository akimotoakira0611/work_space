# System Tools 分析與管理網頁

本專案保留了左側導覽、右側操作的直覺架構。目前首頁整合了 PCIe Margin JSON 分析工具，透過純前端技術進行數據驗證，並以彈出視窗（新 HTML 分頁）呈現結果，確保主操作介面的整潔。

## PCIe Gen6 Margin 分析工具使用說明
* **操作方式：** 在首頁右側點選「選擇 JSON 檔案並開始分析」，可一次多選 (Multiple) 由 AMDXIO 工具生成的 `.json` 報告檔。
* **資料量偵測：** 程式會自動計算總測試筆數 (Runs)。若資料量不足 AMD 規範的 20 筆交互測試門檻，彈出報告將會顯示紅色警告標語。
* ** Criteria 判定：** 程式將嚴格檢驗所有 Runs 中的所有 Lanes，只要有任一數據不滿足最低要求（Vref >= 2 且 UI RL >= 1），即判定為 FAIL。
* **最差通道抓取：** 透過面積計算公式動態篩選出表現最差的 Lane，並於報告頂端標示。
